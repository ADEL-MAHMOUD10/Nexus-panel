# Nexus Panel v1.3.0 — The Apple / Next.js Redesign & Tactile Ergonomics Release

> **Release Tag:** `v1.3.0`  
> **Status:** Production Stable  
> **Kernel Engine:** Xray-core `v26.10.x` & `v26.9.x`  
> **Platforms:** Linux `amd64` / `arm64`, Windows `x64`  

---

## 🌟 Executive Summary

Nexus Panel `v1.3.0` is a comprehensive design, interaction, and visual overhaul inspired by modern Next.js and Apple Pro aesthetics. It replaces all legacy styling with borderless matte cards, introduces an adaptive dual-theme engine (Apple Ultra-Black `#000000` & Warm Linen `#f2eeeb`), deploys tactile micro-interactions across every interactive element, redesigns the health index gauge into organic botanical foliage (ورق شجر), and provides 100% polished Light Mode support for all dialogs and modals.

---

## 🚀 Key Highlights & What's New

### 🎨 1. Apple Pro & Next.js Aesthetic Architecture
- **Obsidian Dark Palette (`#000000` & `#161617`):**
  - Pitch-black background (`#000000`) paired with matte borderless card surfaces (`#161617`) and elevated sub-surfaces (`#1d1d1f`).
  - Seamless borderless cards matching Apple iPhone Pro showcase standards with deep ambient shadows.
  - Electric green accent (`#30d158` / `#50ec83`) for high-visibility telemetry indicators.
- **Warm Linen Light Mode (`#f2eeeb` & `#ffffff`):**
  - Warm, eye-friendly linen canvas (`#f2eeeb`) paired with pure white floating borderless cards (`#ffffff`).
  - High-contrast, crystal-clear typography hierarchy (`#09090b` headings, `#52525b` subtitles).
- **Luxury Theme Toggle:**
  - Tactile interactive toggle button with smooth sun/moon rotation and glowing state transitions.

### 🍃 2. Botanical Foliage Health Index Gauge (ورق شجر)
- Replaced basic straight-line radial gauges with 28 organic botanical tree leaves.
- Each leaf is rendered with an organic lanceolate blade, central midrib vein, lateral secondary veins, and a connecting vine branch arc.
- Dynamic color transitions based on real-time server health (emerald green for optimal health, amber for moderate load, crimson for critical warnings).

### ⚡ 3. Tactile Feedback & Micro-Interactions
- **Header Quick Refresh & Global Sync:**
  - Minimum 750ms visible spin duration guarantees tactile feedback even on ultra-fast (<5ms) localhost responses.
  - Hover pre-rotation (`group-hover:rotate-90 scale-110`) and active press compression (`active:scale-90`).
  - Morphing emerald checkmark badge (`✓`) upon completion with a toast notification confirmation.
  - Global keyboard shortcut **`R`** to sync data anytime.
- **Matrix & Logs Refresh Buttons:**
  - Dedicated tactile spin and checkmark confirmation in both `XrayMetricsModal` ("Xray Core Telemetry Matrix") and `XrayLogModal` ("Xray Core Kernel Logs") as well as `/logs` and `/config`.
- **Interactive Port Copy Pills (`:port`):**
  - Instant morphing feedback: switches to an emerald `<Check />` icon with a `"Copied!"` badge and `active:scale-95` bounce.
- **Modal Ergonomics:**
  - Outside backdrop click dismisses open modals.
  - `Escape` key listener on all modals (`InboundModal`, `ClientModal`, `BackupModal`, `ShareModal`, `UpdatesModal`, `XrayLogModal`, `XrayMetricsModal`).
  - Rotating tactile close button (`X`) with hover scale, 90-degree twist, and an `Esc` keyboard shortcut pill badge.

### ☀️ 4. Complete Light Mode Contrast & Readability Fixes
- Fixed hardcoded `#161617` modal backgrounds across all modals to ensure clean, high-contrast, pure white dialogs with soft drop shadows in light mode.
- Restructured `XrayMetricsModal`, `XrayLogModal`, `BackupModal`, `ClientModal`, `InboundModal`, `ShareModal`, and `UpdatesModal` with semantic, responsive `light/dark` classes.
- Fixed table headers, toolbar filters, log terminal streams, and footers for pristine daylight legibility.

## 🛠️ Quick Installation & Upgrade

### Linux (One-line upgrade):
```bash
curl -fsSL -o /usr/local/bin/nexus https://github.com/ADEL-MAHMOUD10/Nexus-panel/releases/download/v1.3.0/nexus-linux-amd64
chmod +x /usr/local/bin/nexus
systemctl restart nexus
```

### Windows:
Replace `nexus_server.exe` and launch:
```powershell
.\nexus_server.exe
```
Panel interface available at: `http://127.0.0.1:8443`
