# Nexus Panel v1.2.7 Release Notes

### 📦 1-Click Database Backup & Disaster Recovery (النسخ الاحتياطي والاستعادة بنقرة واحدة)
- **Zero-Downtime Live Snapshot:**
  - Backups are created instantly using SQLite `VACUUM INTO 'destPath'` (`GET /api/server/backup` & `/panel/api/server/getDb`), capturing the complete database state without table locks or service downtime.
- **Pre-Flight Integrity & Schema Validation:**
  - Every uploaded `.db` file is strictly checked with `PRAGMA integrity_check == "ok"` and verified to contain the required schema tables (`inbounds`, `clients`, `settings`, `admins`) before any replacement occurs (`POST /api/server/restore` & `/panel/api/server/importDB`).
- **Disaster Protection & Auto-Rollback:**
  - Automatically creates a safety backup (`nexus.db.bak`) before overwriting.
  - Safely flushes and removes active WAL/SHM journal files, reopens connections, and automatically re-applies all active inbound listeners into Xray-core so restored proxies work immediately.
- **Rich User Interface:**
  - Integrated `BackupModal` accessible with one click from both the top navigation header and the Config page, featuring download progress animations, file drop zones, and safety confirmation dialogs.

### ⚡ SQLite Performance & Concurrency Engine
- **Full Index Coverage:** Added database indexes for `inbound_id`, `email`, `last_online`, and `port` for lightning-fast queries during heavy concurrent traffic.
- **WAL & Concurrency Optimization:** Configured `PRAGMA journal_mode = WAL;`, `busy_timeout = 5000;`, and `foreign_keys = ON;`.
- **Atomic Batch Updates:** Grouped client last-online updates into single atomic transactions to eliminate database lock contention.

### 🌐 Resilient Client Online Detection
- 90-second sliding grace period combines real-time gRPC connection telemetry with SQLite `last_online` timestamps, preventing clients from temporarily showing offline during Xray reloads or quick handshakes.

### 📡 Standardized Subscription Subsystem
- Emits RFC/SIP008 compliant `Subscription-Userinfo: upload=...; download=...; total=...; expire=...` and `Profile-Update-Interval: 24` headers on `/sub/{subId}` endpoints, enabling v2rayNG, Streisand, Shadowrocket, and Clash to display real-time client data quotas and expiration dates.

### 🎨 Protocol-First InboundModal UX
- Protocol grid placed as the primary field with dynamic title and remark auto-healing (`SS-2022-PORT`, `Trojan-PORT`, `WG-PORT`), preventing lingering titles when switching between protocols.
