# Nexus Panel v1.3.2 — Label UI, High-Contrast Light Mode & Ergonomics

> **Release Tag:** `v1.3.2`  
> **Status:** Production Stable  
> **Kernel Engine:** Xray-core `v26.10.x` & `v26.9.x`  
> **Platforms:** Linux `amd64` / `arm64`, Windows `x64`  

---

## 🌟 Highlights & What's New in v1.3.2

### 🏷️ 1. Universal Label UI Architecture
- **Tactile Form & Section Badges:**
  - All form field labels across modals and dialogs (`InboundModal`, `ClientModal`, `CertificatesPage`, etc.) have been upgraded into structured UI pill badges.
  - Featuring a subtle background pill, hairline border, uppercase tracking, and an accent indicator dot (`::before`) in sapphire blue (`#2563eb`) in Light Mode and cyber cyan (`#60a5fa`) in Dark Mode.
  - Smooth hover micro-interaction scaling the accent indicator dot (`transform: scale(1.4)`).
  - Checkbox and radio labels remain clean, flexible text rows without unwanted badge styling.

### ☀️ 2. Deep Light Mode Typography & Modal Tab Contrast Fix
- **High-Contrast Dark Typography Across the Entire Site:**
  - All headers, paragraphs, labels, values, and monospace data in Light Mode feature rich, deep, high-contrast dark tones (`#09090b`, `#18181b`, `#27272a`).
  - Solved modal tab contrast bug where active tabs (such as `2. Transport & UDP`) appeared with white text on a light background; active tabs now render with pure white backgrounds, bold dark text (`#09090b`), and subtle elevation shadows.
- **Select & Option Dropdown Popups:**
  - Explicitly enforced `color-scheme: light` on native `<select>` and `<option>` elements in Light Mode, preventing dark OS dropdown popups and ensuring a clean white background with dark text.
- **Sticky Modal Footer & Port Collision Guard:**
  - Added a sticky frosted footer (`backdrop-blur-md`) with dedicated breathing room, preventing the port conflict indicator and action buttons from colliding with form content.

### 🛠️ 3. TCP Header Obfuscation Layout Polish
- Upgraded the `TCP Header Obfuscation` section in `InboundModal` with a dedicated `Terminal` icon container, uppercase mode pill (`NONE` / `HTTP`), and styled dropdown.

### 🐙 4. GitHub Repository Integration
- Added an official GitHub repository icon button in the Top Header with hover and active micro-interactions.
- Added an interactive GitHub repository link row with external link icon in the Sidebar footer, plus top branding link and collapsed icon button.

### 📐 5. Sidebar Ergonomics & Semantic Version Display
- Removed the Server IP button from the sidebar for a cleaner, decluttered navigation panel.
- Sidebar branding version pill dynamically displays a clean two-digit semantic version (`v1.3`), dropping the patch number automatically.

### 🔐 6. Executive Dual-Theme Login Page Restoration
- Restored the exact original dual-theme login page design:
  - In **Light Mode**: Pristine white floating card (`rounded-3xl` / `shadow-2xl`) over the warm linen architectural canvas (`#f2eeeb`), clean non-badge labels, white inputs, and `Sign In →` button.
  - In **Dark Mode**: Signature matte `#0c0d13/85` card with white button and dark text.
  - Dedicated `ThemeToggle` in the top right corner.

## 🛠️ Quick Installation & Upgrade

### Linux (One-line upgrade):
```bash
curl -fsSL -o /usr/local/bin/nexus https://github.com/ADEL-MAHMOUD10/Nexus-panel/releases/download/v1.3.2/nexus-linux-amd64
chmod +x /usr/local/bin/nexus
systemctl restart nexus
```

### Windows:
Replace `nexus_server.exe` with `nexus-windows-amd64.exe` and launch:
```powershell
.\nexus_server.exe
```
Panel interface available at: `http://127.0.0.1:8443`
