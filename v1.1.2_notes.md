# Nexus Panel v1.1.2 — Resilient Online Tracking & Stats Synchronization

## 🚀 What's New in v1.1.2

### 1. 🛡️ Resilient Xray Core gRPC Connection
- Fixed an issue where unsupported user stats methods would tear down the controller's gRPC connection. The connection now remains permanently open and resilient.
- Continuous, uninterrupted real-time speed ($\Delta\text{Bytes}/\Delta t$) calculation for both upload and download streams.

### 2. 🟢 90-Second Online Grace Window (3x-ui standard alignment)
- Expanded client online grace period from 25s to **90 seconds**.
- Connected clients remain reliably listed as `● Online` during idle periods, reading, or intermittent traffic, preventing false `Offline` flips.

### 3. 🌐 API Interoperability with 3x-ui Standards
- Added `"obj"` compatibility wrapper to `/api/inbounds/list` and `/panel/api/inbounds/list` ensuring seamless integration with third-party tools, multi-node managers, and sub-converters.
