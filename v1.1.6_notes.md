# Nexus Core v1.1.6 Release Notes

### 🎯 Dynamic Health Gauge Badge & Zero-Icon Visual Sync
- **Icon Completely Removed**: The static `Sparkles` icon has been completely eradicated.
- **100% Dynamic Color & Status Matching**:
  - Score `> 70%`: 🟢 **Optimal Condition · {Score}% (Higher is better)** with emerald styling (`bg-emerald-500/10 border-emerald-500/30 text-emerald-400`).
  - Score `> 40%` (e.g. `51%`): 🟡 **Moderate Load · {Score}% (Higher is better)** with amber styling (`bg-amber-500/10 border-amber-500/30 text-amber-400`).
  - Score `<= 40%`: 🔴 **Degraded Health · {Score}% (Higher is better)** with rose styling (`bg-rose-500/10 border-rose-500/30 text-rose-400`).
- **No Residual Dots or Static Labels**: Pure typography with glowing themed borders synchronized with the radial arc bars.
