# Nexus Panel v1.1.1 — Real-Time Speed & Telemetry Release

## 🚀 What's New in v1.1.1

### 1. ⚡ Live Client Telemetry & Real-Time Speed (Upload / Download)
- Continuous 2.5s differential rate calculations delivering true per-client upload and download speeds (`↑ Up / ↓ Down`).
- Live `● Online` / `Offline` status tracking with instantaneous state detection.
- Detailed traffic breakdown hover tooltips showing byte-accurate upload, download, and cumulative usage.
- Remaining bandwidth quota accounting with quota limits and expiry countdowns.

### 2. 🎛️ Instant Switch Toggle & Batch Actions Toolbar
- Real-time client enable/disable toggle switch with dynamic memory updates to Xray Core (zero connection disruption for other clients).
- Floating multi-select batch action toolbar: Batch Enable, Batch Disable, Batch Reset Traffic, and Batch Delete.
- Full suite of client actions: 1-click QR code modal, comprehensive Client Details inspector, traffic reset counter, and editing.

### 3. 🛡️ Privacy & Security Enhancements
- **Masked Public IP by Default**: Public IP is shielded by default (`••••••••••••`) across the dashboard and header for stream and screenshot safety, with an interactive eye reveal toggle.
- **Kernel Uptime Formatting**: Human-readable uptime display (`1d 14h 25m`) replacing raw integer seconds.

### 4. 🧠 True Physical Memory (RSS) Footprint
- Accurately reports combined OS Resident Set Size (RSS / Working Set) of both the panel and child Xray Core processes via native OS kernel diagnostics.
- Clarified Health Gauge index with semantic status markers (`0% Degraded` to `100% Optimal Health`).
