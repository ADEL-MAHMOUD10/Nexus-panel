# Nexus Panel v1.3.1 — Mobile Ergonomics, Notification Island & Navigation Polish

> **Release Tag:** `v1.3.1`  
> **Status:** Production Stable  
> **Kernel Engine:** Xray-core `v26.10.x` & `v26.9.x`  
> **Platforms:** Linux `amd64` / `arm64`, Windows `x64`  

---

## 🌟 Highlights & What's New in v1.3.1

### 📱 1. Mobile Bottom Navigation Light Mode Overhaul
- **Dynamic Apple Frosted Backdrop:**
  - In **Light Mode**, the mobile bottom navigation bar features an Apple frosted translucent surface (`bg-white/95 backdrop-blur-2xl`) with hairline border (`border-neutral-200/80`) and upward elevation shadow (`shadow-[0_-4px_24px_rgba(0,0,0,0.06)]`).
  - In **Dark Mode**, retains the pitch-black Apple Pro matte aesthetic (`bg-[#161617]/95`).
- **Active Tab Pill & Text Contrast:**
  - Active indicator pill dynamically adjusts (`bg-neutral-950` in light, `bg-white` in dark).
  - High-contrast text labels and icons (`text-neutral-950 font-bold` in light, `text-white font-bold` in dark).

### 🔔 2. Notification Center & Toast Island Refinements
- **Notification Item Spacing & Clean Borders:**
  - Eliminated corner scalloping caused by touching rounded cards; replaced divider lines with clean `space-y-2` vertical spacing.
  - Each notification is rendered as an independent card with delicate borders (`border-neutral-200` in light, `border-zinc-800` in dark) and soft hover states.
- **Ergonomic Mobile Width:**
  - Refined mobile dropdown and toast notification width (`max-w-[325px]`), leaving comfortable breathing room rather than stretching edge-to-edge across the screen.

### ⚡ 3. System Updates Accessibility on Mobile
- **Universal Update Icon:**
  - Replaced ambiguous security shield with universal `ArrowUpCircle` in the top header.
  - Added an animated amber ping indicator when kernel or panel updates are detected.
- **Mobile Drawer Updates Action:**
  - Added a dedicated "System Updates" action with version badge directly inside `Sidebar.tsx` (accessible via hamburger or "More" mobile tab).
- **Executive Header Updates Trigger:**
  - Added an "Updates" button to the Dashboard Executive Overview header, with responsive flex-wrapping to prevent clipping on compact screens.

## 🛠️ Quick Installation & Upgrade

### Linux (One-line upgrade):
```bash
curl -fsSL -o /usr/local/bin/nexus https://github.com/ADEL-MAHMOUD10/Nexus-panel/releases/download/v1.3.1/nexus-linux-amd64
chmod +x /usr/local/bin/nexus
systemctl restart nexus
```

### Windows:
Replace `nexus_server.exe` with `nexus-windows-amd64.exe` and launch:
```powershell
.\nexus_server.exe
```
Panel interface available at: `http://127.0.0.1:8443`
