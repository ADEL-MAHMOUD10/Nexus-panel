# Nexus Core v1.1.7 Release Notes

### ⚡ Restored Real-Time Online Status & Smooth Speed Rates (Full Symbol Preserved)
- **Restored Complete Runtime Reflection & Protobuf Symbols**:
  - Rebuilt with full symbol tables (restoring full ~35.2MB binaries like `v1.1.3`), resolving gRPC stats deserialization issues caused by symbol stripping in previous interim builds.
  - Xray `StatsService.GetUsersStats` and `QueryStats` reflection calls now succeed 100% reliably.
- **Resilient Online Tracking**:
  - `GetOnlineUsers()` now checks if connections exist with `entry.GetLastSeen() == 0 || (now - entry.GetLastSeen() <= 90)`.
  - Clients connecting or pinging (handshaking) now remain accurately registered as `● Online` with the full 90-second grace period.
- **Smooth Speed Decay**:
  - Replaced abrupt zeroing of speed metrics with a smooth decay algorithm so client speed transfers don't violently flash to zero between sampling intervals.
- **Continuous Reactive Polling**:
  - Frontend now continuously synchronizes `/api/inbounds/list` every 2.5s across all tabs, ensuring the live online client badge and telemetry remain fresh in real-time.
