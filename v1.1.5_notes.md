# Nexus Core v1.1.5 Release Notes

### 🖥️ Desktop Hover-to-Open Sidepanel (Rail Mode)
- **Compact Icon Rail by Default**: On desktop/PC screens, the sidebar collapses into a sleek `68px` icon rail, maximizing widescreen dashboard space.
- **Hover-to-Open Expansion**: Automatically and smoothly unfolds to full `256px` (`w-64`) when the mouse hovers over it, revealing full navigation labels, live counters, badges, and server details.
- **Zero Layout Shifts**: Main dashboard content stays smoothly positioned with dedicated spacing, preventing any jumping or reflows.
- **Pin / Lock Feature**: Includes a subtle pin button allowing users to lock the sidebar in open mode if preferred.

### 📱 Full Mobile Responsiveness & Bottom Navigation Bar
- **Mobile Bottom Quick Nav (`MobileBottomNav`)**: Added an executive mobile bottom bar with quick 1-thumb switching between Dashboard, Inbounds, Clients, Config, and a "More" drawer trigger.
- **Dynamic Mobile Header (`Header`)**:
  - Full mobile search mode with one-tap toggle and clear button.
  - Zero horizontal overflow on narrow screens (320px - 390px).
  - Compact updates & notifications icon triggers.
  - Responsive title truncation.
- **Mobile Viewport Optimization**: Upgraded viewport bounds to `100dvh` to handle mobile browser address bars without clipping.

### 📊 Dynamic Health Index Gauge (`RadialHealthGauge`)
- **Icon Removed**: Eradicated the static sparkles icon as requested.
- **Dynamic Condition Badging**: Live health condition reflecting exact scores:
  - `85% - 100%`: 🟢 **Optimal Health (Score%) · Higher is better**
  - `70% - 84%`: 🟢 **Good Health (Score%) · Higher is better**
  - `40% - 69%`: 🟡 **Moderate Load (Score%) · Higher is better**
  - `< 40%`: 🔴 **Degraded State (Score%) · Higher is better**
- **Subtle Live Pulse Dot**: Minimal pulsing status indicator aligned with executive theme.
