# Nexus Panel v1.1.3 — Responsive Cross-Device & Mobile Layout Release

## 🚀 What's New in v1.1.3

### 1. 📱 Smooth Mobile Navigation Drawer
- Full native mobile drawer experience with a hamburger toggle button in the header (`< md`).
- Soft darkened backdrop overlay with 1-tap dismiss.
- Automatic drawer close on route navigation.
- Desktop remains an unobstructed, executive layout.

### 2. 🎴 Adaptive Client Card View for Mobile Screens
- On mobile phones and compact screens (`< md`), the clients view seamlessly switches from the wide multi-column table to **Executive Client Cards**.
- Each card features:
  - Instant **Enable/Disable switch toggle**.
  - Live **`● Online`** glowing emerald status badge.
  - Byte-accurate **Live Transfer Speed** indicators (`↑ / ↓`).
  - Integrated **Traffic Quota** progress bar with remaining quota & duration calculations.
  - Touch-friendly action buttons (`QR Code & Link`, `Client Details Inspector`, `Reset Traffic`, `Edit`, `Delete`).
- Desktop continues to feature the wide, ultra-dense executive data grid with horizontal scroll protection.

### 3. 📐 Fluid Telemetry & Responsive Grid Refinements
- The **Radial Health Gauge** dynamically scales down on narrow smartphone viewports.
- Responsive core service status grid prevents text clipping on small screens.
- Mobile viewport padding optimized for compact screen real estate (`p-3.5` to `p-6`).
